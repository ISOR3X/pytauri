# Command line interface

!!! warning
    PyTauri's command line interface is still experimental. Visit [the repo](https://github.com/ISOR3X/pytauri-cli) to view the latest updates.

PyTauri ships a CLI python package that offers shortcuts for common commands.

1. Starting a new project
2.

When using [uv], pytauri-cli can quickly be installed with the following command.

```
uv tool install git+https://github.com/ISOR3X/pytauri-cli
```

pytauri-cli can then be accessed from anywhere using `pytauri-cli`.


[uv]: https://docs.astral.sh/uv/
