While PyTauri is built on top of [Tauri](), it can be used without Rust if you prefer to. We ship a Python wheel that bundles the Tauri core and a prebuilt Rust toolchain, so you don't need Rust installed.

:::u-alert{color="info" variant="subtle" icon="i-lucide-info"}
#description
While the Rust version of PyTauri offers hot-reloading for Python code as well, the pure Python version does not.
This is planned for a future update.
:::

### Prerequisites

- [pnpm](https://pnpm.io/): A JavaScript package manager.
- [uv](https://docs.astral.sh/uv/): A Python package and project manager.

### Creating a new PyTauri project

:::u-alert{color="info" variant="subtle" icon="i-lucide-info"}
#description
Currently there is no template generator yet for a pure Python version of PyTauri.
This is planned for a future update.
:::

::steps{level="4"}

#### Create a new uv project

```bash [terminal]
uv init PROJECT_NAME --lib
```

If you already have a Python project you can skip this step.

#### Add PyTauri

Add the PyTauri Wheel as a Python dependency, and then create the files below.

```bash [terminal]
uv add pytauri-wheel
```

```json [app/src-tauri/tauri.conf.json]
{
  "$schema": "https://schema.tauri.app/config/2",
  "productName": "{APP-NAME}-app",
  "version": "0.1.0",
  "identifier": "com.{USER}.{APP-NAME}-app",
  "build": {
    "frontendDist": "../dist"
  },
  "app": {
    "withGlobalTauri": true,
    "windows": [
      {
        "title": "{APP-NAME}-app",
        "width": 800,
        "height": 600
      }
    ]
  },
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}
```

```json [app/src-tauri/capabilities/default.json]
{
  "identifier": "default",
  "description": "Capability for the main window",
  "windows": ["main"],
  "permissions": ["core:default", "pytauri:default"]
}
```

```python [src/PYTHON_PROJECT/__main__.py]
import sys
from os import environ
from pathlib import Path

from anyio.from_thread import start_blocking_portal
from pytauri import Commands
from pytauri_wheel.lib import builder_factory, context_factory

SRC_TAURI_DIR = Path(__file__).parent.parent.parent / "app" / "src-tauri"
DEV_SERVER = environ.get("DEV_SERVER")

commands = Commands()


@commands.command()
async def greet() -> str:
    return sys.version


if DEV_SERVER is not None:
    tauri_config = {
        "build": {
            "frontendDist": DEV_SERVER,
        },
    }
else:
    tauri_config = None


def main() -> int:
    with start_blocking_portal("asyncio") as portal:
        app = builder_factory().build(
            context=context_factory(SRC_TAURI_DIR, tauri_config=tauri_config),
            invoke_handler=commands.generate_handler(portal),
        )
        exit_code = app.run_return()
        return exit_code


if __name__ == "__main__":
    sys.exit(main())
```

#### Add app icon

A app icon is required for the app to run. [The default PyTauri icon can be found here](https://github.com/pytauri/create-pytauri-app/blob/main/templates/%7B%7B%20'.'%20%7D%7D/%7B%7B%20project_name%20%7D%7D/src-tauri/icons/icon.ico)

#### Set up the frontend

Execute the following command from within your Python project.

```bash [terminal]
pnpm create vite
```

Make sure to rename the frontend folder to `app`

#### Connect the frontend to Python

```ts [app/vite.config.ts] {7-13}
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";

// https://vite.dev/config/
export default defineConfig({
  plugins: [vue()],
  clearScreen: false,
  server: {
    port: 1420,
    strictPort: true,
    watch: {
      ignored: ["**/src-tauri/**", "**/.venv/**"],
    },
  },
});
```

### Creating a new PyTauri project with with Rust

The Rust version of PyTauri can be set up easily using [create-pytauri-app](https://github.com/pytauri/create-pytauri-app).

Simply enter the command below and follow the prompts.

```bash [Terminal]
uvx copier copy https://github.com/pytauri/create-pytauri-app .
```

If you're looking to dive deeper into things and want to completely set up a new project by yourself step-by-step, [you can read how to here](./starting-from-scratch.md)
