Welcome to **PyTauri**

PyTauri is a framework that lets you build **native desktop applications** using **Python** for the backend and **modern web technologies** for the frontend, powered by [Tauri](https://tauri.app). It bridges the Python ecosystem with Tauri’s secure, lightweight runtime, enabling you to ship fast, cross-platform applications without requiring Rust expertise.

With PyTauri, you focus on writing Python and frontend code, while Tauri handles window management, system integration, and application packaging for macOS, Linux, and Windows.

## What is PyTauri?

At its core, PyTauri combines three worlds:

- **Python** for application logic and backend services
- **Web frameworks** (such as React, Vue, Svelte, or plain HTML/JS) for the user interface
- **Tauri** as the native shell that securely connects everything together

PyTauri uses Rust internally via PyO3 bindings, but **using Rust is completely optional**. You get access to Tauri’s capabilities—such as IPC, native menus, file system access, and plugins—directly from Python.

This makes PyTauri especially well-suited for:
- Python developers who want to build native apps
- Data, ML, or automation tools with a rich UI
- Teams that prefer web frontends but Python backends

## Key Features

PyTauri includes a range of features designed to make building native applications with Python simple and efficient:

- **Python-powered backend**: Write application logic in Python and reuse existing libraries and tooling.
- **Web-based frontend**: Build user interfaces with your preferred frontend framework or plain HTML, CSS, and JavaScript.
- **Tauri-based runtime**: Leverage Tauri for secure, lightweight native windowing and system integration.
- **Cross-platform support**: Target macOS, Linux, and Windows from a single codebase.
- **Built-in IPC**: Send and receive data between the frontend and Python backend with a clear communication model.
- **Plugin ecosystem**: Use official Tauri plugins to access native functionality.
- **Application bundling**: Package your app into a standalone executable for distribution.
- **Fast iteration**: Support for hot reloading during development to speed up feedback cycles.
